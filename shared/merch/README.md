# Shared merch framework (v1.0.1)

Cart, quote, Stripe Embedded Checkout, and webhook helpers shared by **K-TECH Speedshop** and **C10 United**. Only data access (catalog adapter), page shells, and theme differ per site.

**Changelog:** 1.0.1 — toast never overlaps cart pill; compact mobile toast with pointer-events pass-through; body padding when pill shown.

## KEEP BOTH COPIES BYTE-IDENTICAL

After any change here, copy `shared/merch/` to the other repo, run the sync script in both, and make sure `shared/merch/CHECKSUM` matches:

- K-Tech: `C:\Users\Jason\code\ktechspeedshop`
- C10: `C:\Users\Jason\code\C10United`

```bash
node shared/merch/scripts/sync-merch-core.mjs
node shared/merch/scripts/sync-merch-core.mjs --check
```

## Layout

| Path | Role |
| --- | --- |
| `VERSION` | Semver of this package |
| `CHECKSUM` | sha256 over VERSION + `client/` + `server/` (LF-normalised), generated by sync |
| `client/merch-core.js` | `window.MerchCore` (vanilla ES2017 IIFE) |
| `client/merch-core.css` | Prefixed `.merch-*` styles; colors via CSS variables |
| `server/*.ts` | Framework-agnostic Web API TypeScript |
| `scripts/sync-merch-core.mjs` | Copies client assets → `public/js/`, writes CHECKSUM |

## Cart / server contract

- **Cart line:** `{ id, qty }` (qty 1..99). localStorage key from page config.
- **Quote:** `POST` `{items:[{id,qty}]}` → `{ok:true,cart:{items,subtotal_cents,shipping_cents,total_cents,free_ship_cents}}`. Accepts legacy `variantId` or `slug`+`size`.
- **Checkout:** same body → `{ok:true,clientSecret}`; 503 if Stripe keys missing.
- **Config:** `{publishableKey, stripeJsUrl}`
- **Session status:** `{ok,status,paymentStatus,email,amount_total_cents,shipping_cents,items}`
- **Webhook:** `handleStripeWebhook` verifies HMAC, ignores non-`checkout.session.completed` and wrong `metadata.site`, re-prices, then `hooks.saveOrder` / `hooks.notify`.
- **Shipping:** `shippingCents(subtotal, {flatCents, freeOverCents})` defaults 600 / 7500.
- **Catalog adapter:** `lookupLines(ids) => Map<id, {id,title,label,unit_cents,image?}>`.

## Client

Config from `<script type="application/json" id="merch-config">`. `MerchCore.init()` wires:

- `form[data-merch-add]` (`name="id"`, `name="qty"`)
- `[data-merch-badge]`
- Floating cart pill when `pill: true`
- `[data-merch-mount="cart|checkout|thanks"]`

Theme variables (set in the host stylesheet, not here): `--merch-bg`, `--merch-fg`, `--merch-muted`, `--merch-line`, `--merch-accent`, `--merch-accent-fg`, `--merch-input-bg`, `--merch-input-fg`, `--merch-radius`, `--merch-font`, `--merch-font-display`.
